Netflix Movie Recommendation Assistant (C++)
A simple interactive C++ console program that recommends a Netflix movie based on the user's preferred genre. This project was created as Part 2 of the group assignment for **LDCW6123 - Fundamentals of Digital Competence for Programmer** at Multimedia University (MMU).

📌 Description
Inspired by Netflix's personalized recommendation system, this program asks the user to select a movie genre (Action, Comedy, Sci-Fi, Horror, Animation, Drama, Documentary, or Romance) and then suggests a real Netflix movie title with a short description. It demonstrates basic C++ concepts such as:

- `switch` statements for decision making
- `while` loops for repeated queries
- Input validation using `cin.fail()`, `cin.clear()`, and `cin.ignore()`
- Functions for modular code
- Clear console output formatting


✨ Features
- 8 different movie genres to choose from
- Real Netflix movie recommendations with year and synopsis
- Input validation to handle non-numeric and out-of-range entries
- Loop to allow multiple recommendations until the user exits
- Simple and user-friendly console menu


🚀 How to Run
1. Make sure you have a C++ compiler installed (e.g., `g++`).
2. Clone this repository or download the `.cpp` file.
